Настройки отпусков

Управление лимитами и типами отпусков для сотрудников

Ежегодный оплачиваемый отпуск

Количество дней по умолчанию для всех сотрудников

По умолчанию: 28 дней (стандарт РФ)

Как это работает:

  • Каждому сотруднику доступно указанное количество дней в год
  • При одобрении заявки дни автоматически вычитаются из баланса
  • Если дни закончились, тип отпуска будет недоступен (серым)

Day Off

Дополнительные выходные дни

Доступно для всех сотрудников компании

О Day Off:

  • Day Off появится в выпадающем списке типов отпуска
  • Сотрудники смогут использовать эти дни по своему усмотрению
  • Лимит применяется ко всем сотрудникам одинаково
  • При отключении Day Off исчезнет из списка типов отпуска
