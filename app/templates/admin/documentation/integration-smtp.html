Настройка SMTP

Конфигурация почтового сервера

Для отправки email-уведомлений необходимо настроить SMTP-сервер.

Доступ к настройкам

Перейдите в Система → Настройки → SMTP

Параметры SMTP

Параметр Описание Пример
SMTP-сервер Адрес почтового сервера smtp.gmail.com
Порт Порт подключения 587 (TLS) или 465 (SSL)
Использовать TLS Шифрование соединения Да
Логин Имя пользователя для аутентификации noreply@company.com
Пароль Пароль учетной записи ••••••••
Отправитель Email и имя отправителя Корпоративный портал <noreply@company.com>

Настройка для популярных сервисов

Gmail

  • Сервер: smtp.gmail.com
  • Порт: 587
  • TLS: Да
  • Примечание: Требуется создать пароль приложения в настройках Google

Yandex

  • Сервер: smtp.yandex.ru
  • Порт: 587
  • TLS: Да

Mail.ru

  • Сервер: smtp.mail.ru
  • Порт: 587
  • TLS: Да

Проверка настроек

После заполнения параметров:

  1. Нажмите "Отправить тестовое письмо"
  2. Укажите email для получения тестового письма
  3. Проверьте почту
  4. Если письмо получено - настройки корректны

Типы уведомлений

Система отправляет следующие email-уведомления:

  • Новая заявка на отпуск - руководителю при создании заявки
  • Согласование отпуска - сотруднику о решении руководителя
  • Утверждение HR - сотруднику об окончательном решении
  • Новая заявка на пропуск - службе охраны
  • Новый заказ - ответственному за обработку
  • Дни рождения - напоминания о днях рождения сотрудников
Совет: Используйте отдельную учетную запись для отправки уведомлений (например, noreply@company.com), а не личную почту.
Внимание: Храните пароль SMTP в безопасности. Не используйте личные пароли - создавайте специальные пароли приложений.

Отключение уведомлений

Для временного отключения email-уведомлений:

  • Снимите галочку "Включить SMTP"
  • Сохраните настройки
  • Система продолжит работать, но письма отправляться не будут
