Роли и права доступа

Система ролей

Система использует ролевую модель для управления доступом пользователей к различным функциям портала.

Стандартные роли

Роль Описание Основные права
Администратор Полный доступ ко всем функциям системы
  • Управление пользователями и ролями
  • Настройка системы
  • Управление контентом
  • Просмотр логов
  • Все функции HR и руководителя
HR Управление персоналом и заявками
  • Управление сотрудниками
  • Обработка заявок на отпуск
  • Управление вакансиями
  • Просмотр статистики
Руководитель Управление подчиненными
  • Согласование отпусков подчиненных
  • Просмотр информации о сотрудниках
  • Создание заявок
Сотрудник Базовый доступ к порталу
  • Просмотр новостей и объявлений
  • Создание заявок (пропуска, заказы)
  • Подача заявок на отпуск
  • Использование мессенджера
  • Прохождение тестов и опросов
Охрана Работа с пропусками
  • Просмотр заявок на пропуска
  • Управление доступом

Создание и редактирование ролей

Для управления ролями:

  1. Перейдите в Пользователи → Роли
  2. Нажмите "Добавить роль" для создания новой роли
  3. Укажите название роли и описание
  4. Настройте права доступа для роли
  5. Сохраните изменения

Назначение ролей

Роль назначается пользователю при создании или редактировании учетной записи:

  • Откройте карточку пользователя
  • Выберите роль из выпадающего списка
  • Сохраните изменения
Примечание: Один пользователь может иметь только одну роль. Для предоставления дополнительных прав создайте новую роль с расширенными полномочиями.

Иерархия доступа

Роли имеют следующую иерархию (от большего к меньшему):

  1. Администратор - полный доступ
  2. HR - управление персоналом
  3. Руководитель - управление подчиненными
  4. Сотрудник - базовый доступ
  5. Охрана - специализированный доступ
Внимание: Будьте осторожны при назначении роли "Администратор". Эта роль дает полный доступ ко всем функциям системы, включая удаление данных и изменение настроек.
