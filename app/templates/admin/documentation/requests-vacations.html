Система управления отпусками

Обзор системы

Система отпусков позволяет автоматизировать процесс подачи, согласования и учета отпусков сотрудников с автоматическим контролем лимитов.

Типы отпусков

Тип Описание Учет дней
Ежегодный оплачиваемый Основной отпуск (по умолчанию 28 дней в год) Вычитается из баланса
Day Off Дополнительные выходные дни (если включено в настройках) Вычитается из баланса Day Off
За свой счет Неоплачиваемый отпуск Не учитывается в балансе

Процесс согласования

Заявка на отпуск проходит следующие этапы:

  1. Создание заявки - сотрудник подает заявку
  2. Согласование руководителем - непосредственный руководитель одобряет или отклоняет
  3. Утверждение HR - HR-отдел окончательно утверждает отпуск
  4. Списание дней - дни автоматически вычитаются из баланса при утверждении HR

Обработка заявок (для руководителей)

Руководители могут согласовывать отпуска своих подчиненных:

  1. Перейдите в Отпуска → Согласование
  2. Просмотрите заявки подчиненных
  3. Нажмите "Одобрить" или "Отклонить"
  4. При необходимости укажите комментарий

Обработка заявок (для HR)

HR-специалисты имеют полный доступ ко всем заявкам:

  1. Перейдите в Отпуска → Все заявки
  2. Просмотрите заявки, одобренные руководителями
  3. Проверьте доступный баланс сотрудника
  4. Нажмите "Утвердить" для окончательного одобрения
Важно: Дни отпуска списываются с баланса только после утверждения HR. До этого момента они учитываются как "ожидающие" и блокируют соответствующее количество дней.

Баланс отпускных дней

Система автоматически отслеживает баланс для каждого сотрудника:

  • Всего дней - годовой лимит (настраивается в системе)
  • Использовано - дни утвержденных отпусков
  • Ожидает - дни в заявках на согласовании
  • Доступно - остаток для новых заявок

Ограничения подачи заявок

Система автоматически контролирует лимиты:

  • Если баланс исчерпан, тип отпуска становится недоступным (серым)
  • Учитываются как утвержденные, так и ожидающие заявки
  • Сотрудник видит актуальный баланс при создании заявки
  • Отпуск "За свой счет" всегда доступен

Просмотр статистики

HR и администраторы могут просматривать:

  • График отпусков всех сотрудников
  • Баланс отпускных дней каждого сотрудника
  • Статистику использования отпусков по отделам
  • Историю всех заявок
Совет: Регулярно проверяйте график отпусков, чтобы избежать одновременного отсутствия большого количества сотрудников из одного отдела.

Отмена отпуска

Для отмены утвержденного отпуска:

  1. Найдите заявку в списке
  2. Измените статус на "Отменен"
  3. Дни автоматически вернутся на баланс сотрудника
