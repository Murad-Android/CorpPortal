Настройка меню

Управление пунктами меню

Система позволяет настраивать главное меню портала для разных ролей пользователей.

Доступ к настройкам

Для настройки меню:

  1. Перейдите в Система → Настройки → Меню
  2. Просмотрите текущую структуру меню
  3. Добавьте, измените или удалите пункты меню
  4. Сохраните изменения

Параметры пункта меню

Параметр Описание
Название Текст пункта меню
URL Ссылка на страницу
Иконка Иконка для отображения рядом с названием
Порядок Позиция в меню (сортировка)
Роли Какие роли видят этот пункт меню
Активен Отображается ли пункт в меню

Стандартные пункты меню

  • Главная - главная страница портала
  • Новости - лента новостей компании
  • Сотрудники - справочник сотрудников
  • Отпуска - система управления отпусками
  • Заявки - подача заявок (пропуска, заказы)
  • Мессенджер - внутренний чат
  • Вакансии - открытые вакансии
  • Тесты - обучающие тесты
  • Опросы - опросы сотрудников
Совет: Настройте видимость пунктов меню в зависимости от ролей, чтобы каждый пользователь видел только релевантные для него разделы.
