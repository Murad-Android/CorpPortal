Логи и мониторинг

Система логирования

Портал ведет подробные логи всех действий пользователей и системных событий.

Доступ к логам

Для просмотра логов перейдите в Система → Логи

Типы логов

Тип Описание
Аутентификация Входы и выходы пользователей, неудачные попытки входа
Действия пользователей Создание, изменение, удаление записей
Системные события Запуск/остановка сервисов, ошибки
Безопасность Подозрительная активность, блокировки

Фильтрация логов

Доступные фильтры:

  • По дате - выбор временного диапазона
  • По пользователю - действия конкретного пользователя
  • По типу события - фильтр по категориям
  • По уровню - INFO, WARNING, ERROR, CRITICAL

Информация в логах

Каждая запись лога содержит:

  • Дата и время - когда произошло событие
  • Пользователь - кто выполнил действие
  • IP-адрес - откуда было выполнено действие
  • Действие - что было сделано
  • Объект - над чем было выполнено действие
  • Результат - успех или ошибка

Экспорт логов

Для анализа или архивирования:

  1. Примените необходимые фильтры
  2. Нажмите "Экспортировать"
  3. Выберите формат (CSV, Excel, JSON)
  4. Сохраните файл

Мониторинг системы

Раздел мониторинга показывает:

  • Активные пользователи - кто сейчас онлайн
  • Использование ресурсов - нагрузка на сервер
  • Статистика запросов - количество обращений к системе
  • Ошибки - последние ошибки и предупреждения

Автоматическая очистка логов

Для экономии места на диске:

  • Настройте автоматическое удаление старых логов
  • Укажите срок хранения (например, 90 дней)
  • Система будет автоматически удалять устаревшие записи
Рекомендация: Регулярно проверяйте логи на наличие подозрительной активности или ошибок. Это поможет своевременно выявить проблемы безопасности или технические неполадки.

Уровни логирования

  • DEBUG - детальная информация для отладки (не используется в продакшене)
  • INFO - обычные информационные сообщения
  • WARNING - предупреждения о потенциальных проблемах
  • ERROR - ошибки, требующие внимания
  • CRITICAL - критические ошибки, требующие немедленного вмешательства
Внимание: Логи могут содержать конфиденциальную информацию. Ограничьте доступ к ним только для администраторов.
