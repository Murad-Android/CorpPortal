Управление тестами

Создание теста

Для создания нового теста:

  1. Перейдите в Контент → Тесты
  2. Нажмите "Создать тест"
  3. Заполните информацию о тесте
  4. Добавьте вопросы
  5. Нажмите "Сохранить"

Настройки теста

Параметр Описание
Название Название теста
Описание Описание цели и содержания теста
Активен Доступен ли тест для прохождения
Проходной балл Минимальный балл для успешного прохождения
Время на прохождение Ограничение времени (в минутах)
Показывать результаты Показывать ли правильные ответы после прохождения

Добавление вопросов

Каждый вопрос теста содержит:

  • Текст вопроса - формулировка вопроса
  • Варианты ответов - список возможных ответов
  • Правильный ответ - отметка правильного варианта
  • Баллы - количество баллов за правильный ответ

Просмотр результатов

Для анализа результатов тестирования:

  1. Перейдите в список тестов
  2. Нажмите "Результаты" рядом с нужным тестом
  3. Изучите статистику прохождения

Статистика теста

Страница результатов показывает:

  • Список всех участников
  • Набранные баллы каждого участника
  • Процент правильных ответов
  • Время прохождения
  • Статус (пройден/не пройден)
Примечание: Тесты можно использовать для проверки знаний сотрудников, аттестации или обучения.
