Управление новостями

Создание новости

Для публикации новости на портале:

  1. Перейдите в Контент → Новости
  2. Нажмите "Добавить новость"
  3. Заполните форму создания новости
  4. Нажмите "Опубликовать"

Поля новости

Поле Описание Обязательное
Заголовок Название новости (отображается в списке и на странице новости) Да
Содержание Текст новости с поддержкой HTML-форматирования Да
Изображение Главное изображение новости Нет
Категория Категория новости для группировки Нет
Опубликовано Статус публикации (опубликовано/черновик) Да
Закреплено Закрепить новость вверху списка Нет

Редактирование новости

Для изменения опубликованной новости:

  1. Найдите новость в списке
  2. Нажмите кнопку "Редактировать"
  3. Внесите необходимые изменения
  4. Сохраните изменения

Комментарии к новостям

Пользователи могут оставлять комментарии к новостям. Администратор может:

  • Просматривать все комментарии
  • Удалять неуместные комментарии
  • Модерировать обсуждения

Удаление новости

Для удаления новости:

  1. Найдите новость в списке
  2. Нажмите кнопку "Удалить"
  3. Подтвердите удаление
Совет: Используйте функцию "Закреплено" для важных объявлений, которые должны быть всегда на виду у сотрудников.

Форматирование текста

В поле "Содержание" поддерживается HTML-форматирование:

  • <b> или <strong> - жирный текст
  • <i> или <em> - курсив
  • <u> - подчеркнутый текст
  • <a href="..."> - ссылки
  • <ul>, <ol>, <li> - списки
  • <p> - абзацы
Внимание: При удалении новости также удаляются все комментарии к ней. Это действие необратимо.
