Управление заказами

Обработка заказов

Сотрудники могут подавать заявки на различные заказы (канцелярия, оборудование и т.д.). Для обработки:

  1. Перейдите в Заявки → Заказы
  2. Просмотрите список заявок
  3. Откройте заявку для детального просмотра
  4. Измените статус заявки

Информация в заявке

Каждая заявка на заказ содержит:

  • Название - что нужно заказать
  • Описание - подробное описание заказа
  • Количество - требуемое количество
  • Срочность - приоритет заказа
  • Дата создания - когда была подана заявка
  • Автор - кто подал заявку
  • Статус - текущий статус

Статусы заказов

Статус Описание
Новый Заявка создана, ожидает обработки
В обработке Заказ принят в работу
Выполнен Заказ выполнен и доставлен
Отменен Заказ отменен
Примечание: Рекомендуется регулярно обновлять статусы заказов, чтобы сотрудники были в курсе состояния своих заявок.
