Управление пропусками

Обработка заявок на пропуска

Сотрудники могут подавать заявки на оформление пропусков для посетителей. Для обработки заявок:

  1. Перейдите в Заявки → Пропуска
  2. Просмотрите список заявок
  3. Откройте заявку для детального просмотра
  4. Измените статус заявки

Информация в заявке

Каждая заявка на пропуск содержит:

  • ФИО посетителя - полное имя гостя
  • Организация - компания посетителя
  • Дата визита - планируемая дата посещения
  • Время визита - время прибытия и убытия
  • Цель визита - причина посещения
  • Сопровождающий - сотрудник, который встречает гостя
  • Статус - текущий статус заявки

Статусы заявок

Статус Описание
Новая Заявка только что создана, ожидает рассмотрения
Одобрена Заявка одобрена, пропуск оформлен
Отклонена Заявка отклонена

Работа службы охраны

Пользователи с ролью "Охрана" имеют доступ к:

  • Просмотру всех одобренных пропусков
  • Фильтрации пропусков по дате
  • Поиску посетителей
  • Отметке о прибытии/убытии гостей
Совет: Рекомендуется обрабатывать заявки на пропуска заблаговременно, чтобы избежать задержек при встрече гостей.
