Список пользователей

Путь: Админ-панель → Пользователи → Список пользователей

Обзор

Раздел для просмотра и управления всеми пользователями системы. Здесь вы можете искать пользователей, фильтровать по различным критериям и выполнять массовые операции.

Основные функции

Поиск пользователей

Используйте поле поиска для быстрого нахождения пользователя по:

  • ФИО
  • Email
  • Логину (username)
  • Должности
  • Отделу

Фильтрация

Доступные фильтры:

  • По роли: admin, hr, secretary, user, и пользовательские роли
  • По статусу: активные / неактивные
  • По отделу: выбор из списка отделов
  • По типу: локальные / LDAP пользователи

Столбцы таблицы

Столбец Описание
Фото Аватар пользователя
ФИО Полное имя пользователя
Email Электронная почта
Должность Текущая должность
Отдел Подразделение
Роль Роль в системе
Статус Активен / Неактивен
Последний вход Дата последнего входа в систему

Действия с пользователем

Для каждого пользователя доступны действия:

  • Редактировать - изменение данных пользователя
  • Сбросить пароль - генерация нового пароля
  • Деактивировать - блокировка доступа
  • Удалить - полное удаление (требует подтверждения)

Массовые операции

Выберите несколько пользователей (чекбоксы) для выполнения массовых операций:

  • Экспорт в Excel
  • Массовая деактивация
  • Массовое изменение роли
  • Отправка уведомления

Экспорт данных

Нажмите кнопку "Экспорт" для выгрузки списка пользователей:

  • Excel (.xlsx) - с форматированием и фильтрами
  • CSV (.csv) - для импорта в другие системы
  • PDF (.pdf) - для печати

Совет: Используйте фильтры перед экспортом, чтобы выгрузить только нужных пользователей.
