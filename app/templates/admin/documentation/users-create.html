Создание пользователя

Добавление нового пользователя

Для создания нового пользователя в системе:

  1. Перейдите в раздел Пользователи → Список пользователей
  2. Нажмите кнопку "Добавить пользователя"
  3. Заполните обязательные поля формы
  4. Нажмите "Сохранить"

Обязательные поля

Поле Описание Требования
Логин Уникальное имя пользователя для входа Только латинские буквы, цифры, дефис, подчеркивание
Email Электронная почта пользователя Корректный формат email
Пароль Пароль для входа в систему Минимум 6 символов
Роль Роль пользователя в системе Выбор из списка доступных ролей

Дополнительные поля

  • Имя - имя пользователя
  • Фамилия - фамилия пользователя
  • Отчество - отчество пользователя
  • Телефон - контактный телефон
  • Должность - должность в компании
  • Отдел - подразделение компании
  • Активен - статус активности учетной записи
Важно: При создании пользователя автоматически создается баланс отпускных дней согласно настройкам системы (по умолчанию 28 дней).

Связь с карточкой сотрудника

После создания пользователя рекомендуется:

  1. Создать карточку сотрудника в разделе Сотрудники
  2. Связать пользователя с карточкой сотрудника через поле "Пользователь"
  3. Это позволит отображать полную информацию о сотруднике в системе
Внимание: Логин пользователя должен быть уникальным. Система не позволит создать двух пользователей с одинаковым логином.
