Управление опросами

Создание опроса

Для создания нового опроса:

  1. Перейдите в Контент → Опросы
  2. Нажмите "Создать опрос"
  3. Заполните форму опроса
  4. Добавьте вопросы и варианты ответов
  5. Нажмите "Сохранить"

Настройки опроса

Параметр Описание
Название Название опроса
Описание Краткое описание цели опроса
Активен Доступен ли опрос для прохождения
Анонимный Сохранять ли имена участников
Показывать результаты Могут ли участники видеть результаты после прохождения
Дата начала Дата начала опроса
Дата окончания Дата завершения опроса

Типы вопросов

Система поддерживает различные типы вопросов:

  • Один вариант - выбор одного ответа из списка (radio button)
  • Несколько вариантов - выбор нескольких ответов (checkbox)
  • Текстовый ответ - свободный текстовый ответ
  • Оценка - оценка по шкале (например, от 1 до 5)

Добавление вопросов

Для добавления вопроса в опрос:

  1. В форме создания опроса нажмите "Добавить вопрос"
  2. Введите текст вопроса
  3. Выберите тип вопроса
  4. Добавьте варианты ответов (для вопросов с выбором)
  5. Укажите, является ли вопрос обязательным

Просмотр результатов

Для анализа результатов опроса:

  1. Перейдите в список опросов
  2. Нажмите "Результаты" рядом с нужным опросом
  3. Изучите статистику ответов
  4. При необходимости экспортируйте данные

Статистика опроса

Страница результатов показывает:

  • Общее количество участников
  • Процент прохождения по каждому вопросу
  • Распределение ответов (диаграммы)
  • Текстовые ответы (для открытых вопросов)
  • Список участников (для неанонимных опросов)
Совет: Используйте анонимные опросы для получения более честных ответов на чувствительные темы.

Закрытие опроса

Для завершения опроса:

  1. Откройте опрос для редактирования
  2. Снимите галочку "Активен" или установите дату окончания
  3. Сохраните изменения
Внимание: После закрытия опроса сотрудники не смогут пройти его или изменить свои ответы.
