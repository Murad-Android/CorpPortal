Интеграция с LDAP/Active Directory

Настройка LDAP

Система поддерживает аутентификацию через LDAP/Active Directory для централизованного управления пользователями.

Доступ к настройкам

Для настройки LDAP перейдите в Система → Настройки → LDAP

Параметры подключения

Параметр Описание Пример
Сервер LDAP Адрес LDAP-сервера ldap://dc.company.local
Порт Порт подключения 389 (LDAP) или 636 (LDAPS)
Base DN Базовый DN для поиска DC=company,DC=local
Bind DN DN учетной записи для подключения CN=admin,DC=company,DC=local
Пароль Пароль учетной записи ••••••••
Фильтр пользователей LDAP-фильтр для поиска пользователей (objectClass=person)

Настройка атрибутов

Сопоставление атрибутов LDAP с полями системы:

  • Логин → sAMAccountName или uid
  • Email → mail
  • Имя → givenName
  • Фамилия → sn
  • Отображаемое имя → displayName

Включение LDAP-аутентификации

  1. Заполните все параметры подключения
  2. Нажмите "Проверить подключение" для тестирования
  3. Установите галочку "Включить LDAP"
  4. Сохраните настройки

Синхронизация пользователей

После настройки LDAP:

  • Пользователи могут входить с учетными данными домена
  • При первом входе автоматически создается учетная запись в системе
  • Данные пользователя синхронизируются с LDAP при каждом входе
Примечание: Для работы LDAP через SSL (LDAPS) используйте порт 636 и убедитесь, что сертификат сервера доверенный.

Группы LDAP

Можно настроить автоматическое назначение ролей на основе групп LDAP:

  1. Укажите DN группы в настройках роли
  2. Пользователи из этой группы автоматически получат соответствующую роль
Внимание: При включении LDAP локальные пароли пользователей игнорируются. Аутентификация происходит только через LDAP-сервер.

Отключение LDAP

Для возврата к локальной аутентификации:

  1. Снимите галочку "Включить LDAP"
  2. Сохраните настройки
  3. Пользователи снова смогут входить с локальными паролями
