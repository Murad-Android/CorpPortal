Обзор корпоративного портала

Версия: 3.1

Технологии: Python 3.12, Flask, SQLAlchemy

База данных: SQLite / PostgreSQL

Введение

Корпоративный портал - это комплексная система для управления внутренними процессами компании. Система включает модули для управления пользователями, публикации контента, обработки заявок и интеграции с корпоративными сервисами.

Основные возможности

Управление пользователями

  • Создание и редактирование пользователей
  • Гибкая система ролей и прав доступа
  • Интеграция с Active Directory (LDAP)
  • Автоматическая синхронизация данных

Управление контентом

  • Новости - публикация новостей с комментариями
  • Вакансии - размещение вакансий и управление откликами
  • Опросы - создание опросов с различными типами вопросов
  • Тесты - обучающие тесты с автоматической проверкой
  • Центр безопасности - важная информация по безопасности

Система заявок

  • Пропуска - оформление пропусков для посетителей
  • Заказы - заявки на заказ товаров и оборудования
  • Отпуска - планирование отпусков с автоматическим учетом лимитов

Дополнительные модули

  • Справочник сотрудников
  • Внутренний мессенджер
  • Совместные таблицы
  • Система уведомлений

Структура админ-панели

Админ-панель организована по функциональным разделам:

📊 Панель управления
├── 📰 Контент (новости, вакансии, опросы, тесты)
├── 📋 Заявки (пропуска, заказы, отпуска)
├── 👥 Пользователи (список, роли, сотрудники)
└── ⚙️ Система (настройки, интеграции, логи)

Доступ к админ-панели

Для доступа к админ-панели необходимо:

  1. Иметь учетную запись с правами администратора
  2. Перейти по адресу: /admin
  3. Войти используя свои учетные данные

Важно: Доступ к админ-панели имеют только пользователи с соответствующими правами. Обычные пользователи не увидят ссылку на админ-панель.

Быстрый старт

Для начала работы рекомендуется:

  1. Ознакомиться с разделом Роли и права
  2. Настроить интеграцию с LDAP (если используется)
  3. Настроить SMTP для уведомлений
  4. Создать необходимых пользователей
  5. Настроить меню портала
