Настройки отпусков

Конфигурация системы отпусков

Для настройки параметров отпусков перейдите в Система → Настройки → Отпуска

Основные параметры

Параметр Описание По умолчанию
Дней ежегодного отпуска Количество дней оплачиваемого отпуска в год 28 дней
Включить Day Off Разрешить использование дополнительных выходных Выключено
Дней Day Off Количество дополнительных выходных в год 0 дней

Настройка ежегодного отпуска

Стандартный оплачиваемый отпуск:

  • Укажите количество дней (обычно 28 дней по ТК РФ)
  • Этот лимит применяется ко всем сотрудникам
  • Дни автоматически начисляются при создании пользователя
  • Баланс обновляется ежегодно (можно настроить автоматическое обновление)

Настройка Day Off

Дополнительные выходные дни:

  1. Установите галочку "Включить Day Off"
  2. Укажите количество доступных дней Day Off
  3. Сохраните настройки

После включения Day Off:

  • Тип "Day Off" появится в выпадающем списке при создании заявки
  • Для каждого сотрудника будет создан отдельный баланс Day Off
  • Дни Day Off учитываются отдельно от основного отпуска
Примечание: Day Off обычно используется для дополнительных выходных дней, которые компания предоставляет сотрудникам (например, за переработки или как бонус).

Инициализация настроек

При первом запуске системы необходимо:

  1. Применить миграцию базы данных: flask db upgrade
  2. Запустить скрипт инициализации: python init_vacation_settings.py
  3. Настроить параметры в админ-панели

Обновление баланса сотрудников

Для массового обновления баланса всех сотрудников:

  • Используйте скрипт reset_vacation_balance.py
  • Или настройте автоматическое обновление в начале года
Внимание: Изменение лимитов отпусков не влияет на уже созданные заявки. Новые лимиты применяются только к новым пользователям и при обновлении баланса.

Проверка работы системы

Для тестирования системы отпусков:

  1. Создайте тестового пользователя
  2. Проверьте, что у него есть баланс отпускных дней
  3. Создайте заявку на отпуск
  4. Убедитесь, что дни корректно вычитаются из баланса
  5. Проверьте, что при исчерпании лимита тип отпуска становится недоступным

Подробная инструкция по тестированию доступна в файле TESTING_VACATION_LIMITS.md
