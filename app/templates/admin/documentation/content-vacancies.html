Управление вакансиями

Создание вакансии

Для публикации новой вакансии:

  1. Перейдите в Контент → Вакансии
  2. Нажмите "Добавить вакансию"
  3. Заполните информацию о вакансии
  4. Нажмите "Опубликовать"

Поля вакансии

Поле Описание
Название должности Название вакантной позиции
Отдел Подразделение компании
Описание Подробное описание вакансии, обязанностей и требований
Требования Требования к кандидату (образование, опыт, навыки)
Условия Условия работы (график, зарплата, бонусы)
Контакты Контактная информация для откликов
Активна Статус вакансии (активна/закрыта)

Управление откликами

Система позволяет принимать отклики на вакансии:

  • Сотрудники могут рекомендовать кандидатов
  • Внешние кандидаты могут отправлять резюме
  • Все отклики сохраняются в разделе Заявки → Рекомендации

Просмотр откликов

Для работы с откликами:

  1. Перейдите в Заявки → Рекомендации
  2. Выберите отклик для просмотра
  3. Изучите информацию о кандидате
  4. Измените статус отклика (новый/на рассмотрении/принят/отклонен)

Закрытие вакансии

Когда позиция заполнена:

  1. Откройте вакансию для редактирования
  2. Снимите галочку "Активна"
  3. Сохраните изменения
Примечание: Неактивные вакансии не отображаются в общем списке, но остаются в базе данных для истории.

Удаление вакансии

Для удаления вакансии:

  1. Найдите вакансию в списке
  2. Нажмите кнопку "Удалить"
  3. Подтвердите удаление
Внимание: При удалении вакансии также удаляются все связанные с ней отклики. Рекомендуется закрывать вакансии вместо удаления.
