# Corporate Notify — Десктопный клиент уведомлений

Python-приложение. Работает как фоновый процесс, показывает приветствия и уведомления.

## Функции

- Приветствие на полный экран при первом запуске за день (по времени: утро/день/вечер)
- Дополнительные приветствия в 12:00 и 18:20
- Проверка уведомлений портала каждые 60 секунд (Windows toast)
- Окно поверх всех окон, нельзя свернуть, только закрыть крестиком
- Имя пользователя берётся с портала по Windows-логину

## Сборка

```
notify_build.bat
```

Результат: `dist\CorporateNotify.exe` (один файл, без зависимостей)

## Развёртывание

1. Собрать exe
2. Запустить `install.bat` от администратора на целевых ПК
3. Или распространить через GPO

## Ручной запуск (для разработки)

```
pip install pywebview win10toast
python notify.py
```

## Настройка

Отредактируйте переменные в начале `notify.py`:
- `portalUrl` — адрес портала
- `checkInterval` — интервал проверки уведомлений (секунды)
