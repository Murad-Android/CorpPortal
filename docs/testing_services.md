# Руководство по сервисам тестирования

## Обзор

Сервисы тестирования - это система управления тестовыми окружениями и сервисами для разработки и тестирования.

## Возможности

### Управление сервисами
- Создание, редактирование, удаление сервисов
- Включение/выключение сервисов
- Категоризация по окружениям (dev, test, staging, prod)
- Отслеживание версий и технологий

### Информация о сервисе
- Название и описание
- URL для доступа
- Версия
- Технологический стек
- Документация
- Ответственное лицо и контакты

### Логирование
Все действия логируются:
- Доступ к сервису
- Включение/выключение
- Редактирование
- Удаление

## Использование

### Создание сервиса
1. Перейдите в **Сервисы тестирования**
2. Нажмите **"Добавить сервис"**
3. Заполните поля:
   - **Название** (обязательно)
   - **Окружение** (dev/test/staging/prod)
   - **Описание**
   - **URL сервиса**
   - **Версия**
   - **Технологии**
   - **URL документации**
   - **Ответственный**
   - **Email для связи**
4. Отметьте чекбоксы:
   - ☑ Активен
   - ☑ Доступен
5. Нажмите **"Создать"**

### Включение/выключение сервиса
На странице списка сервисов используйте переключатель справа от названия.

Сервис можно выключить если:
- Проводится обслуживание
- Сервис временно недоступен
- Нужно ограничить доступ

### Доступ к сервису
1. Найдите нужный сервис в списке
2. Нажмите кнопку с иконкой внешней ссылки
3. Откроется URL сервиса в новой вкладке
4. Доступ будет залогирован

### Просмотр информации
1. Нажмите **"Подробнее"** на карточке сервиса
2. Просмотрите полную информацию
3. Перейдите к документации если нужно

## Окружения

### Development (dev)
- Для разработки
- Частые изменения
- Может быть нестабильным

### Test (test)
- Для тестирования
- Автоматические тесты
- Изолированная среда

### Staging (staging)
- Предпродакшн
- Финальное тестирование
- Копия продакшна

### Production (prod)
- Боевое окружение
- Стабильная версия
- Ограниченный доступ

## Права в системе

Для работы с сервисами нужны права:
- `testing_services_view` - просмотр списка
- `testing_services_create` - создание сервисов
- `testing_services_edit` - редактирование
- `testing_services_delete` - удаление
- `testing_services_toggle` - включение/выключение

Администраторы имеют полный доступ.

## Интеграция

### Добавление в меню
Сервисы автоматически доступны по адресу `/testing`

### API endpoints
- `GET /testing` - список сервисов
- `GET /testing/<id>` - просмотр сервиса
- `POST /testing/<id>/toggle` - включение/выключение
- `POST /testing/<id>/access` - логирование доступа

- `testing_services` - основная таблица с сервисами
- `testing_service_logs` - логи использования

## Рекомендации

1. **Используйте понятные названия** - чтобы было ясно, что это за сервис
2. **Указывайте версии** - для отслеживания изменений
3. **Добавляйте документацию** - ссылки на wiki или docs
4. **Назначайте ответственных** - для быстрой связи при проблемах
5. **Выключайте неиспользуемые** - чтобы не загромождать список
6. **Группируйте по окружениям** - для удобной навигации
