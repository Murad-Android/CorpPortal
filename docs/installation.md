# Руководство по установке новых функций

## Обзор

Данное руководство описывает установку двух новых функций:
1. **Хранилище паролей** с AES-256 шифрованием
2. **Сервисы тестирования** с управлением окружениями

## Предварительные требования

- Python 3.8+
- Flask приложение запущено
- Доступ к базе данных
- Права администратора

## Шаг 1: Установка зависимостей

Убедитесь, что установлена библиотека для шифрования:

```bash
cd corp
pip install pycryptodome
```

Или обновите requirements.txt:

```bash
pip install -r requirements.txt
```

## Шаг 2: Применение миграции базы данных

Выполните миграцию для создания новых таблиц:

```bash
cd corp
flask db upgrade
```

Это создаст следующие таблицы:
- `password_vault` - хранилище паролей
- `password_vault_permissions` - права доступа к паролям
- `password_vault_logs` - логи доступа к хранилищу
- `testing_services` - сервисы тестирования
- `testing_service_logs` - логи использования сервисов

## Шаг 3: Настройка мастер-ключа шифрования

**КРИТИЧЕСКИ ВАЖНО!** Установите мастер-ключ для шифрования паролей.

### Для разработки:

```bash
export VAULT_MASTER_KEY="dev-key-32-characters-long-12"
```

### Для продакшена:

Создайте надежный ключ (минимум 32 символа):

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Установите его в переменную окружения:

```bash
export VAULT_MASTER_KEY="ваш-сгенерированный-ключ"
```

Или добавьте в `.env` файл:

```
VAULT_MASTER_KEY=ваш-сгенерированный-ключ
```

**ВАЖНО:** Храните мастер-ключ в безопасном месте! Без него невозможно расшифровать пароли.

## Шаг 4: Настройка прав доступа

### 4.1 Войдите как администратор

Перейдите в админ-панель: `/admin`

### 4.2 Настройте права для ролей

1. Перейдите в **Пользователи → Роли**
2. Выберите роль для редактирования
3. В разделе **Безопасность** отметьте нужные права:
   - ☑ Просмотр хранилища паролей
   - ☑ Создание записей паролей
   - ☑ Редактирование паролей
   - ☑ Удаление паролей
   - ☑ Предоставление доступа

4. В разделе **Тестирование** отметьте нужные права:
   - ☑ Просмотр сервисов
   - ☑ Создание сервисов
   - ☑ Редактирование сервисов
   - ☑ Удаление сервисов
   - ☑ Вкл/Выкл сервисов

5. Сохраните изменения

### 4.3 Рекомендуемые настройки прав

**Администратор:**
- Все права (галочка "Полный доступ")

**HR-менеджер:**
- Просмотр хранилища паролей
- Просмотр сервисов

**IT-специалист:**
- Все права на хранилище паролей
- Все права на сервисы тестирования

**Обычный пользователь:**
- Без доступа (или только просмотр по необходимости)

- Видимость: по желанию

**Сервисы тестирования:**
- Название: `Сервисы тестирования`

- Видимость: по желанию

## Использование

### Хранилище паролей

**Создание пароля:**
1. Нажмите **Добавить пароль**
2. Заполните:
   - Название (обязательно)
   - Название сервиса
   - URL
   - Логин
   - Пароль (будет зашифрован)
   - Категория
   - Заметки
3. Отметьте "Общий доступ" если нужно
4. Сохраните

**Просмотр пароля:**
1. Откройте запись
2. Нажмите на иконку глаза для показа пароля
3. Нажмите "Копировать" для копирования в буфер

**Предоставление доступа:**
1. Откройте запись
2. Нажмите иконку "Поделиться"
3. Выберите пользователя
4. Отметьте нужные права:
   - Просмотр
   - Редактирование
   - Удаление
   - Предоставление доступа
5. Сохраните

### Сервисы тестирования

**Создание сервиса:**
1. Нажмите **Добавить сервис**
2. Заполните:
   - Название (обязательно)
   - Описание
   - URL
   - Окружение (dev/test/staging/prod)
   - Версия
   - Технологии
   - URL документации
   - Ответственный
   - Email
3. Отметьте "Активен" и "Доступен"
4. Сохраните

**Управление сервисом:**
- Используйте переключатель для вкл/выкл сервиса
- Нажмите "Подробнее" для просмотра информации
- Нажмите на иконку для перехода к сервису (логируется)

## Безопасность

### Хранилище паролей

1. **Шифрование:**
   - Используется AES-256-GCM
   - Каждый пароль имеет уникальную соль
   - PBKDF2 с 100,000 итераций

2. **Логирование:**
   - Все действия логируются
   - Записывается: пользователь, действие, IP, время
   - Доступные действия: view, edit, delete, share, copy

3. **Права доступа:**
   - Владелец имеет полный доступ
   - Можно предоставить гранулярные права
   - Админ видит все записи

### Сервисы тестирования

1. **Логирование:**
   - Логируется доступ к сервисам
   - Записывается: пользователь, сервис, IP, время

2. **Управление:**
   - Только пользователи с правами могут управлять
   - Включение/выключение логируется

## Резервное копирование

### Важно для хранилища паролей:

1. **Сохраните мастер-ключ:**
   ```bash
   echo $VAULT_MASTER_KEY > vault_key_backup.txt
   ```
   Храните в безопасном месте!

2. **Резервная копия БД:**
   ```bash
   # SQLite
   cp instance/portal.db instance/portal_backup.db
   
   # PostgreSQL
   pg_dump dbname > backup.sql
   ```

3. **Восстановление:**
   - Восстановите БД из резервной копии
   - Установите тот же мастер-ключ
   - Без правильного ключа пароли не расшифруются!

## Устранение неполадок

### Ошибка: "Ошибка дешифрования"

**Причина:** Неправильный мастер-ключ или ключ изменился

**Решение:**
1. Проверьте переменную окружения `VAULT_MASTER_KEY`
2. Убедитесь, что используется тот же ключ, что при шифровании
3. Восстановите ключ из резервной копии

### Ошибка: "У вас нет доступа"

**Причина:** Недостаточно прав

**Решение:**
1. Войдите как администратор
2. Перейдите в **Пользователи → Роли**
3. Настройте права для нужной роли

### Сервисы не отображаются в меню

**Причина:** Нет прав доступа

**Решение:**
1. Проверьте права пользователя
2. Убедитесь, что роль имеет права на просмотр

### Миграция не применяется

**Причина:** Конфликт версий или ошибка в БД

**Решение:**
```bash
# Проверьте текущую версию
flask db current

# Посмотрите историю
flask db history

# Попробуйте снова
flask db upgrade

# Если не помогает, откатите и примените заново
flask db downgrade
flask db upgrade
```
