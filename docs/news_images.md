# Руководство по работе с изображениями в новостях

## Новые возможности

Добавлена полная поддержка изображений в новостях:
1. **Обложка новости** - главное изображение, отображается в списке и на странице новости
2. **Изображения в контенте** - можно добавлять изображения прямо в текст новости

## Обложка новости

### Добавление обложки

1. Откройте форму создания/редактирования новости в админ-панели
2. Найдите поле **"Обложка новости"**
3. Нажмите **"Выберите файл"** и выберите изображение
4. Сохраните новость

**Рекомендации:**
- Размер: 1200x630px (оптимально для соцсетей)
- Форматы: JPG, PNG, WebP
- Максимальный размер: зависит от настроек сервера

### Изменение обложки

1. Откройте новость для редактирования
2. Текущая обложка отображается над полем загрузки
3. Выберите новый файл - старая обложка будет заменена
4. Или отметьте **"Удалить текущую обложку"** чтобы удалить без замены

### Отображение обложки

- **В списке новостей**: обложка отображается слева от текста (256x192px)
- **На странице новости**: обложка отображается во всю ширину сверху (высота 384px)
- Если обложки нет - отображается только текст

## Изображения в контенте

### Добавление изображения в текст

**Способ 1: Кнопка в редакторе**
1. Поставьте курсор в нужное место текста
2. Нажмите кнопку с иконкой изображения в панели инструментов
3. Выберите файл на компьютере
4. Изображение автоматически загрузится и вставится в текст

**Способ 2: Markdown синтаксис**
```markdown
![Описание изображения](URL_изображения)
```

### Форматирование изображений

В Markdown редакторе можно использовать:

```markdown
# Обычное изображение
![Описание](url)

# Изображение с ссылкой
[![Описание](url_изображения)](url_ссылки)
```

### Где хранятся изображения

- **Обложки**: `app/static/uploads/news/`
- **Изображения контента**: `app/static/uploads/news/content/`

Файлы автоматически получают уникальные имена с timestamp.

## Примеры использования

### Новость с обложкой

1. Создайте новость
2. Загрузите обложку (например, фото с мероприятия)
3. Напишите текст
4. Опубликуйте

Обложка будет привлекать внимание в ленте новостей.

### Новость с галереей

1. Создайте новость
2. В тексте добавьте несколько изображений через кнопку загрузки
3. Между изображениями добавьте описания

```markdown
## Фотоотчет с мероприятия

![Открытие мероприятия](url1)

Торжественное открытие прошло в главном зале...

![Выступление спикера](url2)

Главный спикер рассказал о...

![Награждение победителей](url3)
```

### Новость с инфографикой

1. Подготовьте инфографику в графическом редакторе
2. Загрузите как обложку или в контент
3. Добавьте текстовое описание

## Технические детали

### Поддерживаемые форматы

- **JPG/JPEG** - для фотографий
- **PNG** - для изображений с прозрачностью
- **GIF** - для анимации
- **WebP** - современный формат с хорошим сжатием

### Безопасность

- Все файлы проходят проверку типа
- Имена файлов очищаются (secure_filename)
- Добавляется timestamp для уникальности
- Только авторизованные пользователи с правами могут загружать

### API для загрузки

**Endpoint:** `POST /admin/news/upload-image`

**Параметры:**
- `image` - файл изображения (multipart/form-data)

**Ответ:**
```json
{
  "success": true,
  "url": "/static/uploads/news/content/20260202_123456_image.jpg",
  "filename": "20260202_123456_image.jpg"
}
```

## Миграция существующих новостей

Если у вас есть новости без обложек:

1. Откройте новость для редактирования
2. Добавьте подходящую обложку
3. Сохраните

Новости без обложек продолжат работать, просто без изображения.

## Оптимизация изображений

Рекомендации для лучшей производительности:

1. **Сжимайте изображения** перед загрузкой
   - Используйте TinyPNG, ImageOptim или аналоги
   - Целевой размер: 100-300 KB для обложек

2. **Правильный размер**
   - Обложки: 1200x630px
   - Изображения в контенте: не более 1920px по ширине

3. **Формат WebP**
   - Лучшее сжатие при хорошем качестве
   - Поддерживается всеми современными браузерами

## Устранение проблем

### Изображение не загружается

1. Проверьте формат файла (должен быть JPG, PNG, GIF или WebP)
2. Проверьте размер файла (не должен превышать лимит сервера)
3. Проверьте права доступа к папкам uploads

### Изображение не отображается

1. Проверьте, что файл существует в папке `static/uploads/news/`
2. Проверьте путь в базе данных
3. Проверьте права доступа к файлу

### Ошибка при загрузке

1. Откройте консоль браузера (F12)
2. Посмотрите ошибку в Network
3. Проверьте логи сервера
