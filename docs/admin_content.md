## Новости

**Путь:** Админ-панель → Контент → Новости

### Создание новости

1. **Основная информация**
   ```
   Заголовок*
   ├── Краткий и информативный
   ├── Максимум 255 символов
   └── Отображается в списке и карточке

   Краткое описание
   ├── 1-2 предложения
   ├── Максимум 500 символов
   └── Отображается в превью

   Содержание*
   ├── Полный текст новости
   ├── Поддержка HTML
   ├── Вставка изображений
   └── Форматирование текста
   ```

2. **Изображение**
   - Обложка новости
   - Форматы: JPG, PNG, GIF
   - Рекомендуемый размер: 1200x630px
   - Максимальный размер: 10 МБ
   - Автоматическое сжатие

3. **Настройки публикации**
   ```
   Опубликовать
   ├── Да - новость видна всем
   └── Нет - черновик

   Закрепить
   ├── Да - отображается вверху списка
   └── Нет - обычная сортировка

   Комментарии
   ├── Разрешены - пользователи могут комментировать
   └── Запрещены - комментарии отключены
   ```

### Редактирование новости

**Путь:** Админ-панель → Контент → Новости → [Выбрать новость]

- Изменение любых полей
- Изменение изображения
- Изменение статуса публикации
- Управление комментариями

### Управление комментариями

**Функции:**
- Просмотр всех комментариев к новости
- Удаление неподходящих комментариев
- Блокировка комментариев к конкретной новости
- Модерация (требует право `comments_moderate`)

**Удаление комментария:**
- Автор комментария может удалить свой комментарий
- Администратор/HR может удалить любой комментарий
- Удаленный комментарий помечается как "[удалено]"

### Статистика

Для каждой новости доступна статистика:
- Количество просмотров
- Количество комментариев
- Дата создания и последнего изменения
- Автор новости

## Вакансии

**Путь:** Админ-панель → Контент → Вакансии

### Создание вакансии

1. **Основная информация**
   ```
   Название должности*
   └── Например: "Senior Python Developer"

   Отдел
   └── Подразделение компании

   Тип занятости
   ├── Полная занятость
   ├── Частичная занятость
   ├── Проектная работа
   └── Стажировка
   ```

2. **Описание вакансии**
   ```
   Описание*
   ├── Общая информация о позиции
   ├── Задачи и обязанности
   └── Поддержка форматирования

   Требования*
   ├── Необходимые навыки
   ├── Опыт работы
   └── Образование

   Условия
   ├── График работы
   ├── Офис/удаленка
   └── Дополнительные бонусы
   ```

3. **Зарплата**
   ```
   Зарплата от
   └── Минимальная сумма (опционально)

   Зарплата до
   └── Максимальная сумма (опционально)

   Примечание: Можно не указывать или указать "по договоренности"
   ```

4. **Контакты**
   ```
   Email для откликов
   └── Куда отправлять резюме

   Телефон
   └── Контактный телефон (опционально)
   ```

5. **Статус**
   ```
   Активна
   ├── Да - вакансия отображается на портале
   └── Нет - вакансия скрыта
   ```

### Управление откликами

**Путь:** Админ-панель → Контент → Вакансии → [Выбрать вакансию] → Отклики

**Информация об отклике:**
- ФИО кандидата
- Email и телефон
- Прикрепленное резюме
- Сопроводительное письмо
- Дата отклика
- Статус обработки

**Действия:**
- Скачать резюме
- Отметить как "Просмотрено"
- Отметить как "Приглашен на собеседование"
- Отметить как "Отказ"
- Удалить отклик

**Уведомления:**
- HR получает email при новом отклике
- Можно настроить автоответ кандидату

## Опросы

**Путь:** Админ-панель → Контент → Опросы

### Создание опроса

1. **Основная информация**
   ```
   Название опроса*
   └── Краткое и понятное название

   Описание
   └── Дополнительная информация об опросе
   ```

2. **Вопросы**
   ```
   Текст вопроса*
   └── Формулировка вопроса

   Тип ответа
   ├── Один вариант (radio)
   ├── Несколько вариантов (checkbox)
   ├── Текстовый ответ
   └── Оценка (1-5, 1-10)

   Варианты ответов
   └── Список вариантов (для выбора)
   ```

   **Добавление вопросов:**
   - Нажмите "Добавить вопрос"
   - Заполните поля
   - Можно добавить неограниченное количество
   - Изменить порядок перетаскиванием

3. **Настройки**
   ```
   Анонимный
   ├── Да - ответы без привязки к пользователю
   └── Нет - фиксируется автор ответа

   Показывать результаты
   ├── Сразу - после прохождения
   ├── После окончания - когда опрос закрыт
   └── Никогда - только для администраторов

   Дата начала
   └── Когда опрос становится доступным

   Дата окончания
   └── Когда опрос закрывается

   Опубликован
   ├── Да - опрос доступен пользователям
   └── Нет - черновик
   ```

### Просмотр результатов

**Путь:** Админ-панель → Контент → Опросы → [Выбрать опрос] → Результаты

**Статистика:**
- Общее количество ответов
- Процент прохождения
- Детальная статистика по каждому вопросу
- Графики и диаграммы
- Список участников (если не анонимный)

**Экспорт:**
- Excel - полные данные с графиками
- CSV - сырые данные для анализа
- PDF - отчет для презентации

## Тесты

**Путь:** Админ-панель → Контент → Тесты

### Создание теста

1. **Основная информация**
   ```
   Название теста*
   └── Например: "Тест по охране труда"

   Описание
   └── Инструкция для прохождения

   Категория
   ├── Обучение
   ├── Аттестация
   ├── Безопасность
   └── Другое
   ```

2. **Вопросы**
   ```
   Текст вопроса*
   └── Формулировка вопроса

   Тип вопроса
   ├── Один правильный ответ
   ├── Несколько правильных ответов
   └── Текстовый ответ

   Варианты ответов
   ├── Текст варианта
   └── Отметка "Правильный ответ"

   Баллы за вопрос
   └── Вес вопроса в общей оценке
   ```

3. **Настройки теста**
   ```
   Проходной балл
   ├── Минимальный процент для прохождения
   └── Например: 70%

   Ограничение времени
   ├── Время на прохождение (минуты)
   └── 0 = без ограничения

   Количество попыток
   ├── Сколько раз можно пройти
   └── 0 = неограниченно

   Перемешивать вопросы
   ├── Да - случайный порядок
   └── Нет - фиксированный порядок

   Перемешивать ответы
   ├── Да - случайный порядок вариантов
   └── Нет - фиксированный порядок

   Показывать правильные ответы
   ├── Сразу - после каждого вопроса
   ├── В конце - после завершения
   └── Никогда - только результат

   Обязательный
   ├── Да - требуется для всех сотрудников
   └── Нет - добровольное прохождение
   ```

### Просмотр результатов

**Путь:** Админ-панель → Контент → Тесты → [Выбрать тест] → Результаты

**Статистика:**
- Список всех попыток
- ФИО сотрудника
- Дата и время прохождения
- Набранные баллы
- Процент правильных ответов
- Статус (пройден/не пройден)
- Время прохождения

**Детальный просмотр:**
- Ответы на каждый вопрос
- Правильные/неправильные ответы
- Комментарии (если есть)

**Экспорт:**
- Excel - полный отчет
- PDF - сертификат о прохождении

## Центр безопасности

**Путь:** Админ-панель → Контент → Центр безопасности

### Создание статьи

1. **Основная информация**
   ```
   Заголовок*
   └── Название статьи

   Краткое описание
   └── Краткая суть (1-2 предложения)

   Содержание*
   └── Полный текст статьи
   ```

2. **Настройки**
   ```
   Приоритет
   ├── Критический (красный)
   ├── Высокий (оранжевый)
   ├── Средний (желтый)
   └── Информационный (синий)

   Иконка
   ├── Выбор из библиотеки FontAwesome
   └── Например: shield-alt, lock, exclamation-triangle

   Опубликовано
   ├── Да - статья видна всем
   └── Нет - черновик
   ```

### Категории статей

Рекомендуемые категории:
- **Информационная безопасность** - защита данных, пароли
- **Физическая безопасность** - пропускной режим, эвакуация
- **Охрана труда** - правила безопасности на рабочем месте
- **Пожарная безопасность** - действия при пожаре
- **Кибербезопасность** - защита от вирусов, фишинга

### Отображение

Статьи отображаются на странице "Центр безопасности":
- Сортировка по приоритету
- Карточки с иконками и цветовой индикацией
- Поиск по статьям
- Фильтрация по приоритету
