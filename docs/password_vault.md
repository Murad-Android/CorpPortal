# Руководство по хранилищу паролей

## Обзор

Хранилище паролей - это безопасная система для хранения и управления паролями с использованием шифрования AES-256.

## Возможности

### Шифрование
- **AES-256-GCM** - надежное шифрование
- **PBKDF2** - получение ключа из мастер-пароля
- **Уникальная соль** для каждого пароля
- **Автоматическое шифрование/дешифрование**

### Права доступа
- **Чтение** - просмотр пароля
- **Редактирование** - изменение записи
- **Удаление** - удаление записи
- **Предоставление доступа** - возможность делиться паролем

### Логирование
Все действия логируются:
- Просмотр пароля
- Редактирование
- Удаление
- Предоставление/отзыв доступа
- Копирование пароля

## Использование

### Создание записи
1. Перейдите в **Хранилище паролей**
2. Нажмите **"Добавить пароль"**
3. Заполните поля:
   - Название (обязательно)
   - Сервис
   - URL
   - Логин
   - Пароль (обязательно)
   - Категория
   - Заметки
4. Отметьте "Разрешить предоставление доступа" если нужно
5. Нажмите **"Создать"**

### Просмотр пароля
1. Откройте запись
2. Нажмите на иконку глаза чтобы показать пароль
3. Нажмите **"Копировать"** чтобы скопировать в буфер

### Предоставление доступа
1. Откройте запись
2. Нажмите кнопку **"Поделиться"** (зеленая)
3. Выберите пользователя
4. Отметьте права:
   - ☑ Чтение
   - ☐ Редактирование
   - ☐ Удаление
   - ☐ Предоставление доступа
5. Нажмите **"Предоставить доступ"**

### Отзыв доступа
1. Откройте запись
2. Нажмите **"Поделиться"**
3. Найдите пользователя в списке
4. Нажмите **"Отозвать"**

## Права в системе

Для работы с хранилищем нужны права:
- `password_vault_view` - просмотр хранилища
- `password_vault_create` - создание записей
- `password_vault_edit` - редактирование
- `password_vault_delete` - удаление
- `password_vault_share` - предоставление доступа

Администраторы имеют полный доступ ко всем записям.

## Безопасность

### Мастер-ключ
Хранится в переменной окружения `VAULT_MASTER_KEY`.

**ВАЖНО:** В продакшене обязательно установите надежный мастер-ключ!

```bash
export VAULT_MASTER_KEY="your-very-secure-master-key-here"
```

### Рекомендации
1. Используйте сложный мастер-ключ (минимум 32 символа)
2. Регулярно проверяйте логи доступа
3. Предоставляйте минимальные необходимые права
4. Используйте категории для организации паролей
5. Добавляйте заметки с важной информацией

## API

### Копирование пароля
```javascript
POST /vault/<id>/copy-password
```

Возвращает расшифрованный пароль для копирования в буфер обмена.
