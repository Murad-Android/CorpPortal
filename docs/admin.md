## Введение

Корпоративный портал - это комплексная система для управления внутренними процессами компании, включающая:

- Управление пользователями и правами доступа
- Публикацию новостей и объявлений
- Управление вакансиями и откликами
- Систему заявок (пропуска, заказы)
- Планирование отпусков
- Опросы и тестирование сотрудников
- Внутренний мессенджер
- Справочник сотрудников
- Центр безопасности

**Версия:** 3.1  
**Технологии:** Python 3.12, Flask, SQLAlchemy, SQLite/PostgreSQL  
**Лицензия:** Proprietary

## Доступ к админ-панели

### Вход в систему

1. Откройте браузер и перейдите по адресу: `https://your-portal.com/admin`
2. Введите логин и пароль администратора
3. После успешной авторизации вы попадете на главную страницу админ-панели

### Требования к браузеру

- Google Chrome 90+
- Mozilla Firefox 88+
- Microsoft Edge 90+
- Safari 14+

### Права доступа

Для доступа к админ-панели пользователь должен иметь одну из ролей:
- **admin** - полный доступ ко всем функциям
- **hr** - управление персоналом, новостями, вакансиями, отпусками
- **secretary** - обработка заявок на пропуска и заказы
- Пользовательские роли с соответствующими правами

## Структура админ-панели

Админ-панель разделена на несколько основных разделов:

### Боковое меню

```
📊 Панель управления (главная)
├── 📰 Контент
│   ├── Новости
│   ├── Вакансии
│   ├── Опросы
│   ├── Тесты
│   └── Центр безопасности
├── 📋 Заявки
│   ├── Пропуска
│   ├── Заказы товаров
│   └── Отпуска
├── 👥 Пользователи
│   ├── Список пользователей
│   ├── Роли и права
│   └── Сотрудники
└── ⚙️ Система
    ├── Настройки
    ├── Меню
    ├── LDAP
    ├── SMTP
    ├── Отпуска
    └── Логи
```

### Главная страница

Отображает ключевые метрики:
- Общее количество пользователей
- Активные пользователи
- Количество новостей
- Количество вакансий
- Ожидающие заявки (пропуска, заказы, отпуска)
- Последние действия в системе
