## Список пользователей

**Путь:** Админ-панель → Пользователи → Список пользователей

### Функции

1. **Просмотр списка**
   - Таблица со всеми пользователями системы
   - Поиск по имени, email, должности
   - Фильтрация по роли, статусу, отделу
   - Сортировка по любому столбцу

2. **Столбцы таблицы**
   - Фото профиля
   - ФИО
   - Email
   - Должность
   - Отдел
   - Роль
   - Статус (активен/неактивен)
   - Дата создания
   - Последний вход
   - Действия (редактировать, удалить)

3. **Массовые операции**
   - Экспорт в Excel
   - Массовая деактивация
   - Массовое изменение роли

## Создание пользователя

**Путь:** Админ-панель → Пользователи → Создать пользователя

### Обязательные поля

```
Логин (username)*
├── Уникальный идентификатор
├── Только латиница, цифры, _, -
└── Минимум 3 символа

Email*
├── Уникальный email адрес
├── Используется для уведомлений
└── Формат: user@domain.com

Пароль*
├── Минимум 8 символов
├── Рекомендуется: буквы, цифры, спецсимволы
└── Можно сгенерировать автоматически

Роль*
├── Определяет права доступа
└── Выбор из списка ролей
```

### Дополнительные поля

```
Личные данные
├── Фамилия
├── Имя
├── Отчество
└── Дата рождения

Рабочая информация
├── Должность
├── Отдел
├── Телефон (рабочий)
├── Внутренний телефон
├── Местоположение (офис, этаж)
├── Дата приема на работу
└── Руководитель (выбор из списка)

Контакты
├── Личный телефон
└── Дополнительный email

Фото профиля
├── Загрузка изображения
├── Форматы: JPG, PNG
├── Максимальный размер: 5 МБ
└── Автоматическое изменение размера
```

### Процесс создания

1. Нажмите кнопку **"Создать пользователя"**
2. Заполните обязательные поля
3. Заполните дополнительные поля (рекомендуется)
4. Загрузите фото профиля (опционально)
5. Выберите роль
6. Укажите руководителя (если есть)
7. Нажмите **"Сохранить"**

### Автоматическая генерация пароля

Система может сгенерировать безопасный пароль:
- Длина: 12 символов
- Включает: заглавные, строчные буквы, цифры
- Пароль отображается один раз при создании
- Рекомендуется отправить пароль пользователю по защищенному каналу

### Уведомления

После создания пользователя:
- Пользователь получает email с данными для входа (если настроен SMTP)
- Руководитель получает уведомление о новом подчиненном
- Запись добавляется в журнал аудита

## Редактирование пользователя

**Путь:** Админ-панель → Пользователи → [Выбрать пользователя] → Редактировать

### Доступные действия

1. **Изменение личных данных**
   - ФИО, дата рождения
   - Контактная информация
   - Фото профиля

2. **Изменение рабочей информации**
   - Должность, отдел
   - Руководитель
   - Дата приема

3. **Изменение роли**
   - Выбор новой роли
   - Права применяются немедленно
   - Пользователь получает уведомление

4. **Сброс пароля**
   - Генерация нового пароля
   - Отправка на email
   - Принудительная смена при входе

5. **Деактивация/Активация**
   - Деактивация блокирует вход
   - Данные сохраняются
   - Можно активировать повторно

6. **Удаление**
   - Безвозвратное удаление
   - Требует подтверждения
   - Удаляются все связанные данные

### Особенности

**Нельзя изменить:**
- Логин (username) - уникальный идентификатор
- Дату создания
- Историю входов

**Требуют осторожности:**
- Изменение email - влияет на уведомления
- Изменение роли - влияет на доступ
- Удаление - необратимо

## Управление ролями

**Путь:** Админ-панель → Пользователи → Роли и права

### Системные роли

Предустановленные роли (нельзя удалить):

#### 1. Administrator (admin)
```
Права: Полный доступ ко всем функциям
Описание: Главный администратор системы
Количество: Рекомендуется 1-2 пользователя
```

#### 2. HR Manager (hr)
```
Права:
├── Управление новостями
├── Управление вакансиями
├── Управление опросами и тестами
├── Обработка заявок на отпуск
├── Просмотр пользователей
└── Управление сотрудниками

Описание: HR-менеджер, управление персоналом
```

#### 3. Secretary (secretary)
```
Права:
├── Обработка заявок на пропуска
├── Обработка заявок на заказы
└── Просмотр пользователей

Описание: Секретарь, обработка заявок
```

#### 4. User (user)
```
Права: Базовый доступ к порталу
Описание: Обычный сотрудник
```

### Создание пользовательской роли

1. Нажмите **"Создать роль"**
2. Заполните поля:
   ```
   Название (name)*
   ├── Уникальный идентификатор
   ├── Только латиница, без пробелов
   └── Пример: content_manager

   Отображаемое название*
   ├── Название на русском
   └── Пример: Контент-менеджер

   Описание
   └── Краткое описание роли
   ```

3. Выберите права доступа (см. ниже)
4. Нажмите **"Сохранить"**

## Система прав доступа

### Категории прав

#### Контент
```
news
├── Создание и редактирование новостей
├── Публикация/снятие с публикации
└── Управление комментариями

vacancies
├── Создание и редактирование вакансий
├── Просмотр откликов
└── Управление статусами

surveys
├── Создание опросов
├── Просмотр результатов
└── Экспорт данных

tests
├── Создание тестов
├── Просмотр результатов
└── Управление вопросами

security_articles
├── Создание статей центра безопасности
└── Управление категориями

comments_moderate
└── Удаление любых комментариев
```

#### Заявки
```
passes
├── Просмотр заявок на пропуска
├── Одобрение/отклонение
└── Экспорт списков

orders
├── Просмотр заявок на заказы
├── Обработка заявок
└── Управление статусами

vacations
├── Просмотр всех заявок на отпуск
├── Одобрение/отклонение (HR)
├── Управление правилами конфликтов
└── Настройка лимитов отпусков
```

#### Пользователи
```
users_view
└── Просмотр списка пользователей

users_create
└── Создание новых пользователей

users_edit
└── Редактирование данных пользователей

users_delete
└── Удаление пользователей

roles_manage
├── Создание и редактирование ролей
└── Управление правами
```

#### Система
```
settings_general
└── Общие настройки портала

settings_ldap
├── Настройка LDAP/AD
├── Синхронизация пользователей
└── Маппинг атрибутов

settings_smtp
├── Настройка почтового сервера
└── Тестирование отправки

settings_menu
└── Настройка пунктов меню

logs_view
└── Просмотр журнала действий
```

#### Специальные
```
all
├── Полный доступ ко всем функциям
└── Эквивалент роли Administrator
```

### Комбинирование прав

Права можно комбинировать для создания специализированных ролей:

**Пример 1: Контент-менеджер**
```
Права:
├── news
├── surveys
├── tests
└── users_view

Описание: Управление контентом без доступа к настройкам
```

**Пример 2: Менеджер по персоналу**
```
Права:
├── vacancies
├── vacations
├── users_view
├── users_edit
└── surveys

Описание: Работа с персоналом и вакансиями
```

**Пример 3: Офис-менеджер**
```
Права:
├── passes
├── orders
└── users_view

Описание: Обработка заявок и просмотр сотрудников
```

### Рекомендации по назначению ролей

1. **Принцип минимальных привилегий**
   - Назначайте только необходимые права
   - Регулярно проверяйте актуальность прав
   - Удаляйте неиспользуемые роли

2. **Разделение обязанностей**
   - Не давайте одному пользователю все права
   - Разделяйте административные функции
   - Используйте специализированные роли

3. **Документирование**
   - Описывайте назначение каждой роли
   - Ведите список пользователей с расширенными правами
   - Фиксируйте изменения прав

4. **Аудит**
   - Регулярно проверяйте назначенные роли
   - Отслеживайте действия администраторов
   - Используйте журнал аудита

## Импорт пользователей

**Путь:** Админ-панель → Пользователи → Импорт

### Из Excel/CSV

1. Подготовьте файл с колонками:
   ```
   username,email,firstname,lastname,middlename,position,department,phone
   ```

2. Загрузите файл через форму импорта
3. Проверьте предпросмотр данных
4. Выберите роль по умолчанию
5. Нажмите **"Импортировать"**

### Из LDAP/Active Directory

См. раздел [Интеграции - LDAP](README_ADMIN_INTEGRATIONS.md#ldap)

## Экспорт пользователей

**Путь:** Админ-панель → Пользователи → Экспорт

### Форматы экспорта

- **Excel (.xlsx)** - полная информация с форматированием
- **CSV (.csv)** - для импорта в другие системы
- **PDF (.pdf)** - для печати и архивирования

### Настройки экспорта

- Выбор полей для экспорта
- Фильтрация по роли, отделу, статусу
- Сортировка данных
- Включение/исключение фотографий
